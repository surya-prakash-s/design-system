## 2026-08-10 - Dynamic Label Context in Pill Remove Action Buttons
**Learning:** In list and group contexts, action elements (such as close/remove buttons) embedded within Pill components must dynamically include the pill's custom label in their `title` and `assistiveText` (e.g., "Remove [Pill Label]") rather than defaulting to a generic static label like "Remove". This provides crucial context for screen reader users, satisfying WCAG 2.1 accessibility guidelines and preventing redundant/unclear interactions when multiple pills are present on a single page.
**Action:** Always ensure that when designing or refactoring collection items or removable tokens, accessibility helper attributes on interactive child elements dynamically fetch and interpolate parent element label texts instead of hardcoding static descriptions.
